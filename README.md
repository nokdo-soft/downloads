# Nokdo 다운로드 (설치본 공개 배포)

[Nokdo](https://nokdosoft.com/) 프로그램의 **설치본(실행 파일)만** 올리는 공개 저장소입니다. 소스 코드는 비공개입니다.

## 받는 법
각 프로그램의 설치본은 [Releases](../../releases)에 제품별 태그로 있습니다. 예: ieldeck-v1.0.6.

설치한 뒤 처음 실행할 때, 메일 인증으로 받은 **다운로드 코드**를 입력해야 사용할 수 있습니다.
메일 인증·코드 발급: https://my.nokdosoft.com/

## 제품
- **Fieldeck** — 원격 데스크톱(RDP) 다중 접속·현장 대시보드 관리 (Windows 10/11 64비트)
