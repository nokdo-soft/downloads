# Nokdo 다운로드 (설치본 공개 배포)

[Nokdo](https://nokdosoft.com/) 프로그램의 **설치본(실행 파일)만** 올리는 공개 저장소입니다. 소스 코드는 비공개입니다.

## 받는 법 — 메일 인증 방식
이 프로그램들은 **메일 인증 방식**으로 배포됩니다.

1. https://my.nokdosoft.com/ 에서 메일로 인증하면 인증 코드를 받습니다.
2. 아래 [Releases](../../releases)에서 설치 파일을 내려받아 설치합니다. (제품별 태그, 예: `fieldeck-v1.0.6`)
3. 프로그램을 처음 실행할 때 받은 코드를 한 번 입력하면 됩니다.

## 제품
- **Fieldeck** — 원격 데스크톱(RDP) 다중 접속·현장 대시보드 관리 (Windows 10/11 64비트)
